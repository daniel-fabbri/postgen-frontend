# PostGen Frontend

Frontend application for PostGen - AI-powered social media post generator

## Features

- 🎨 Modern UI with dark mode support
- 🤖 AI-powered content generation
- 📱 Responsive design
- ⚡ Built with React + Vite
- 🎯 Tailwind CSS for styling

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Build

To build for production:
```bash
npm run build
```

## Technologies

- React 18
- Vite
- Tailwind CSS
- React Router
- Axios
- Lucide React (icons)
